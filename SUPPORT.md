# Getting help

Comvivo is **not released yet**, so there is no "it broke" support to give — but questions are
welcome and the answers will shape the documentation.

## Where to ask

| | |
|---|---|
| **A question** | [Discussions → Q&A](https://github.com/faizannraza/comvivo/discussions/categories/q-a) |
| **An idea** | [Discussions → Ideas](https://github.com/faizannraza/comvivo/discussions/categories/ideas) |
| **A bug** | [Issues](https://github.com/faizannraza/comvivo/issues) — but check [`docs/plan/STATUS.md`](docs/plan/STATUS.md) first, because the honest answer for most of the product today is "not built yet" |
| **A vulnerability** | **Privately.** [SECURITY.md](SECURITY.md). Never a public issue. |
| **Conduct** | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

A real-time chat space may be added later. GitHub Discussions is the guaranteed home and will stay
the place where answers are findable by the next person with the same question.

## Before you ask

- [`docs/plan/STATUS.md`](docs/plan/STATUS.md) — what exists today, and what every decision was.
- [`docs/plan/`](docs/plan/) — the complete plan, including the subsystems not built yet.
- The docs site, once it exists.

## When you do ask

Please include the version or commit, how you are running it, and what you expected instead.

**Never paste real chat content.** Not yours and not anybody else's — a support thread is public
and permanent. If you need to show a conversation, the simulator generates a realistic one.
