<CardGrid stagger>
  <Card title="It belongs to the group" icon="approve-check">
    Not one person's assistant that others can talk to. Comvivo has members with roles, a
    constitution the group writes together, and actions that run with the authority of whoever
    asked — never more.
  </Card>
  <Card title="Discretion by architecture" icon="seti:lock">
    A group chat is not one audience. What a teenager tells Comvivo privately does not surface in
    the kitchen group. That is enforced by an information-flow model with machine-checked
    invariants, not by asking a model to be careful.
  </Card>
  <Card title="Quiet by default" icon="comment">
    An assistant in a family chat that chatters is an assistant people mute. Comvivo speaks when
    it is useful, respects quiet hours, and has a budget for how often it may interrupt.
  </Card>
  <Card title="Yours, on your machine" icon="laptop">
    Self-hosted, Apache-2.0, and **no product telemetry**: no analytics, no usage counting, no
    crash reporting, not even opt-in. The one request Comvivo can make on its own behalf is an
    update check — off by default, and served from a host that gives us no request logs, so
    installs cannot be counted. Export everything, delete anything.

    This site measures aggregate traffic with a self-hosted, cookieless install and publishes the
    dashboard. That is the website, not the product.
  </Card>
</CardGrid>
