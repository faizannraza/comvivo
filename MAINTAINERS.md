## Becoming one

[GOVERNANCE.md](GOVERNANCE.md) has the ladder: Contributor → Triager → Committer → Maintainer. The
route is sustained contribution and judgement, not volume, and non-code work counts.

## What this project needs

Honestly stated, in the order it would help:

1. **A second maintainer.** Everything else on this list is downstream of it — the conduct contact
   needs two people, protected-area reviews need two approvals, and one maintainer is a single
   point of failure for a project people would be trusting with their household.
2. **Red-team scenarios.** Ways to make Comvivo reveal something it should not. No production code
   required, and it is the work most directly aimed at what this project claims.
3. **Review of the plan.** [`docs/plan/`](docs/plan/) is public and complete. Finding a wrong
   assumption there is worth more than finding a bug in the code implementing it.
